# BDII-Inatel
Repositório da disciplina S202-L (Laboratório de Banco de Dados II) no meu curso no Inatel.

## Descrição

O estudo dessa matéria teve como objetivo explorar e demonstrar o uso de principalmente dois tipos de bancos de dados não relacionais:

1. **MongoDB:** Banco de dados orientado a documentos amplamente utilizado para armazenar dados semi-estruturados. Este banco de dados oferece flexibilidade na modelagem de dados e é ideal para cenários onde os esquemas de dados podem evoluir com o tempo.

2. **Neo4j:** Banco de dados orientado a grafos que é especialmente eficaz na modelagem e consulta de dados interconectados. É usado para cenários em que as relações entre os dados são cruciais.

## Conteúdo

O repositório contém o seguinte:

- [Projeto MongoDB](./Exercício_Avaliativo_01_MongoDB): Projeto simples que simula motoristas de aplicativo.

- [Projeto Neo4J](./Exercicio_Avaliativo_02_Neo4J): Projeto simples que faz várias interações com uma base de dados de professores.
